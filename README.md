# Multiple Data Remover Aadhaar Card
This project was developed in Python using the Flask framework to process and clean JSON data.
The main task was to identify and remove duplicate Aadhaar entries from the dataset.
We focused on creating a clear, efficient method to separate and validate the data.
The solution was built during a 2-day hackathon that encouraged fast, creative problem-solving.
